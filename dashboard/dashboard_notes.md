# Dashboard Notes

This folder is reserved for Power BI or Tableau screenshots after the marts are connected to a BI tool.

Recommended dashboard pages:

1. **Executive Overview**
   - Total processed reviews
   - Average rating
   - Review volume trend
   - Rating distribution
   - Quality watchlist count

2. **Product Performance**
   - Top products by review volume
   - Average rating by product
   - Helpful vote rate
   - High-volume low-rating watchlist

3. **Review Trends**
   - Monthly review count
   - Monthly average rating
   - Helpful vote volume over time

4. **Data Quality Monitor**
   - Valid rows
   - Missing required fields
   - Review text coverage
   - Helpful vote coverage

The intended BI data sources are the CSV marts in `data/marts/`.
